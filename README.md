## 🚀 Featured Projects

### 🧠 [MedGuard RAG – Medical Question Answering System](https://github.com/vijay-aid-007/Med-Guard-RAG)

A medical domain Retrieval-Augmented Generation application designed to provide context-grounded answers using medical knowledge sources.

**Key Technical Components:**
- FAISS-based vector retrieval
- PubMedBERT embeddings
- MedCPT cross-encoder reranking
- Hybrid retrieval and HyDE
- Groq LLM integration with local Ollama fallback
- Personally identifiable information detection using Presidio

**Project Highlights:** 40K+ indexed vectors | RAGAS Context Precision: 1.00 | Faithfulness: 0.75

**Tech:** Python, FAISS, Hugging Face, MedCPT, Groq, Ollama, RAG

---

### 🏢 [Enterprise Intelligence Platform](https://github.com/vijay-aid-007/Enterprise-Intel)

An AI-powered enterprise intelligence application combining predictive Machine Learning, document intelligence, and agent-based workflows.

**Key Technical Components:**
- ML preprocessing, feature engineering, and model comparison
- PDF, DOCX, and CSV document processing
- RAG-based document retrieval with citations
- LLM-powered contextual recommendations
- Agent routing for document search, analytics, calculations, and reporting
- Streamlit frontend and FastAPI backend

**Tech:** Python, FastAPI, Streamlit, Scikit-Learn, RAG, LLMs, Vector Search

### 💳 Credit Card Approval Prediction

An end-to-end Machine Learning project for predicting credit card approval risk using applicant and credit history information.

**Key Technical Components:**
- Large-scale dataset processing (777K+ records)
- Missing-value treatment and feature engineering
- Class imbalance handling using SMOTE
- Logistic Regression, AdaBoost, Gradient Boosting, and XGBoost
- Model evaluation using classification metrics

**Project Highlights:** Approximately 90.47% accuracy with an F1-score of approximately 0.922 in the evaluated model.

**Tech:** Python, Pandas, NumPy, Scikit-Learn, XGBoost, SMOTE
